# Aetherixx



Учебный веб-интерфейс цифрового рабочего пространства, выполненный в рамках курсового проекта.

Сайт предназначен для работы с заметками, задачами и проектами прямо в браузере.



## Назначение проекта



Проект представляет собой клиентскую часть веб-приложения для личной организации учебных и рабочих материалов.

Пользователь может зарегистрироваться, войти в систему, перейти в рабочую область, создавать заметки, добавлять задачи и отслеживать прогресс проектов.



Проект не использует сервер, базу данных и сложные фреймворки.

Вся логика выполняется на стороне браузера с помощью HTML, CSS и JavaScript.



## Основные возможности



* главная страница с описанием сервиса;

* страница регистрации пользователя;

* страница входа в систему;

* демонстрационный вход через тестового пользователя;

* рабочая область пользователя;

* отображение имени пользователя после входа;

* просмотр количества заметок, задач и проектов;

* добавление быстрых задач;

* отметка задачи как выполненной;

* удаление задач;

* создание заметок с названием и текстом;

* удаление заметок;

* создание проектов с названием, описанием и процентом выполнения;

* изменение прогресса проекта;

* автоматическое определение статуса проекта по проценту выполнения;

* удаление проектов;

* блок быстрых заметок в рабочей области;

* отображение активности за последние дни;

* переключение светлой и тёмной темы;

* сохранение данных в `localStorage`;

* адаптивная вёрстка для разных размеров экрана.



## Технологии



* HTML5;

* CSS3;

* JavaScript;

* `localStorage`;

* адаптивная вёрстка через медиазапросы.



Фреймворки, серверные языки и базы данных в проекте не используются.

## Описание файлов



`index.html`

Содержит главную страницу проекта: шапку, навигацию, описание сервиса, главный экран и ссылки на вход или регистрацию.



`login.html`

Содержит форму входа пользователя. На странице пользователь вводит логин и пароль для перехода в рабочую область.



`register.html`

Содержит форму регистрации нового пользователя. Пользователь указывает имя, логин, пароль и цель использования сервиса.



`workspace.html`

Содержит основную рабочую область пользователя. Здесь отображаются приветствие, статистика по заметкам, задачам и проектам, быстрые задачи, быстрые заметки и активность.



`notes.html`

Содержит раздел заметок. Пользователь может создать заметку с названием и текстом, а также удалить ненужную заметку.



`tasks.html`

Содержит раздел задач. Пользователь может добавить задачу, отметить её выполненной или удалить.



`projects.html`

Содержит раздел проектов. Пользователь может добавить проект, указать описание и процент выполнения, а затем изменять прогресс проекта.



`css/`

Папка со стилями страниц. Каждый CSS-файл отвечает за внешний вид отдельной страницы проекта: цвета, отступы, карточки, формы, сетки, адаптивность и тёмную тему.



`js/index.js`

Содержит JavaScript-логику главной страницы.



`js/login.js`

Содержит логику входа в систему. Проверяет заполнение полей, сверяет введённые данные с демо-пользователем или сохранёнными пользователями и сохраняет текущего пользователя в `localStorage`.



`js/register.js`

Содержит логику регистрации. Проверяет заполнение полей, не допускает повторения логина, создаёт нового пользователя и сохраняет его в `localStorage`.



`js/workspace.js`

Содержит основную логику рабочей области: загрузку данных, отображение имени пользователя, подсчёт заметок, задач и проектов, добавление быстрых задач, сохранение быстрых заметок, переключение темы и отображение активности.



`js/notes.js`

Содержит логику раздела заметок: загрузку заметок, создание новых заметок, удаление заметок, сохранение данных и переключение темы.



`js/tasks.js`

Содержит логику раздела задач: загрузку задач, добавление новых задач, отметку выполнения, удаление задач, подсчёт количества задач и переключение темы.



`js/projects.js`

Содержит логику раздела проектов: загрузку проектов, создание проекта, изменение процента выполнения, определение статуса проекта, удаление проекта и переключение темы.



## Запуск проекта



Для запуска не требуется установка зависимостей.



Достаточно открыть файл:



```text

index.html

```



в современном браузере.



Также можно открыть проект через локальный сервер или расширение Live Server в редакторе кода.



## Регистрация и вход



В проекте реализована имитация регистрации и авторизации.



При регистрации пользователь указывает:



* имя;

* логин или email;

* пароль;

* цель использования сервиса.



После успешной регистрации данные пользователя сохраняются в `localStorage`, а пользователь автоматически переходит в рабочую область.



Для входа можно использовать зарегистрированного пользователя или демонстрационные данные:



```text

Логин: admin

Пароль: admin

```



После успешного входа информация о текущем пользователе сохраняется в `localStorage`.



## Заметки



Раздел заметок позволяет пользователю создавать короткие записи.



Форма заметки содержит поля:



* название заметки;

* текст заметки.



Оба поля являются обязательными.

Если пользователь пытается создать пустую заметку, появляется предупреждение.



После добавления заметка сохраняется в `localStorage` под ключом:



```text

aetherixxNotes

```



Пользователь может удалить любую заметку. После удаления список заметок обновляется.



## Задачи



Раздел задач позволяет пользователю вести список дел.



Пользователь может:



* добавить новую задачу;

* отметить задачу как выполненную;

* вернуть задачу в невыполненное состояние;

* удалить задачу;

* добавить задачу нажатием клавиши Enter.



Задачи сохраняются в `localStorage` под ключом:



```text

aetherixxTasks

```



Количество задач отображается на странице и обновляется после изменения списка.



## Проекты



Раздел проектов предназначен для отслеживания учебных или личных проектов.



При создании проекта пользователь указывает:



* название проекта;

* описание проекта;

* процент выполнения.



Название проекта является обязательным.

Если описание не заполнено, проект создаётся с текстом по умолчанию.



Прогресс проекта можно изменять кнопками:



* минус 10%;

* плюс 10%.



Процент выполнения ограничен значениями от `0` до `100`.



В зависимости от процента проект получает статус:



* `Старт` — если прогресс меньше 35%;

* `В процессе` — если прогресс от 35% до 69%;

* `Почти готово` — если прогресс от 70% до 99%;

* `Готово` — если прогресс равен 100%.



Проекты сохраняются в `localStorage` под ключом:



```text

aetherixxProjects

```



## Рабочая область



После входа пользователь попадает в рабочую область.



В рабочей области отображаются:



* приветствие с именем пользователя;

* количество заметок;

* количество задач;

* количество проектов;

* список быстрых задач;

* поле быстрых заметок;

* блок активности за последние дни;

* ссылки на основные разделы проекта.



Быстрые заметки сохраняются в `localStorage` под ключом:



```text

aetherixxQuickNotes

```



## Сохранение данных



Проект использует `localStorage`, поэтому данные сохраняются в браузере пользователя.



Основные ключи хранения:



```text

aetherixxUsers

aetherixxCurrentUser

aetherixxUserName

aetherixxGoal

aetherixxNotes

aetherixxTasks

aetherixxProjects

aetherixxQuickNotes

aetherixxTheme

```



Данные не отправляются на сервер и не доступны с другого устройства или другого браузера.



## Тёмная тема



В проекте реализовано переключение светлой и тёмной темы.



При переключении темы на страницу добавляется или убирается CSS-класс:



```text

dark

```



Выбранная тема сохраняется в `localStorage` под ключом:



```text

aetherixxTheme

```



Благодаря этому после перезагрузки страницы выбранная тема сохраняется.



## Адаптивность



Сайт адаптирован под разные размеры экрана.



На широком экране:



* главный экран отображается в две колонки;

* рабочая область использует карточки и сетки;

* навигация расположена в верхней части страницы;

* блоки заметок, задач и проектов отображаются в удобном виде.



На средних экранах:



* двухколоночные блоки перестраиваются;

* карточки становятся уже;

* отступы уменьшаются;

* элементы интерфейса остаются читаемыми.



На маленьких экранах:



* основные блоки переходят в один столбец;

* кнопки и формы занимают больше ширины;

* уменьшаются размеры заголовков;

* навигация и карточки адаптируются под мобильный экран.

Проект является учебным, поэтому:



* данные не отправляются на сервер;

* нет настоящей базы данных;

* нет защищённой авторизации;

* пароль хранится только в браузере в учебных целях;

* нет восстановления пароля;

* нет синхронизации между устройствами;

* нет личного кабинета на сервере;

* все данные хранятся только на стороне браузера.
